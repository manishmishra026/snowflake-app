Welcome to Snowflake Tables Browser

This application demonstrates three ways to query Snowflake tables:

1️⃣ Service Principal Flow

Query tables using the application's service principal credentials. No authentication required.

2️⃣ User Authentication Flow (OBO)

Query tables using your own Azure AD credentials. Uses on-behalf-of token exchange. Must be logged in.

3️⃣ Service Account Flow

Query tables using a direct database user (webapp_user) and password. No client authentication required.
